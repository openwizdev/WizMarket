# Hosted Coding-Agent Clouds Census (2026-11-27)

Primary-source census of **76** hosted coding-agent cloud services (**68** active/beta, **8** recently sunsetting, shut down, or pivoted in 2026) verified against official documentation, OpenAPI specifications, pricing pages, changelogs, and GitHub repositories as of 2026-11-27/28.

Machine-readable data: [`census/agent-clouds.json`](agent-clouds.json). Any attribute that could not be verified from primary sources is marked `unverified`.

## Top-15 Build-First List for OpenWiz

Prioritized for OpenWiz's `driver` v1 contract (programmatic start, check, wake/follow-up, stop/cancel, and machine-readable usage/cost signals), active maintenance, and user reach:

1. **[Cloudroom](https://www.cloudroom.dev)** (Cloudroom · Fit 5/5 · `driver (already available as an OpenWiz v1 driver)`) — Already a working OpenWiz v1 driver with full CLI start/show/tell/stop/usage control (`room-cli`), 10+ harnesses on users' own subscriptions, zero token markup, and a 1,000-credit/mo free tier.
2. **[Cursor Cloud Agents](https://cursor.com/docs/cloud-agent)** (Cursor (Anysphere) · Fit 5/5 · `driver (and harness row via Cursor CLI)`) — Public beta v1 REST API (`POST /v1/agents`, follow-up/steer `/runs`, SSE streaming, `DELETE`) covering GitHub/GitLab/Bitbucket/ADO with massive developer adoption and Enterprise Admin/Analytics APIs.
3. **[Devin](https://devin.ai)** (Cognition AI · Fit 5/5 · `driver (and optional harness row for local Devin CLI)`) — Mature org-scoped v3 REST API (`POST /v3/organizations/{org_id}/sessions`, archive, enterprise consumption/metrics endpoints), Linux/macOS/Windows VMs, and an accessible $20/mo Pro entry tier.
4. **[Factory (Droids & Droid Computers)](https://factory.com)** (Factory · Fit 5/5 · `driver (cloud Sessions/Execute API and local Droid CLI harness row)`) — Complete OpenAPI (`POST /api/v0/sessions`, `POST /api/v0/droid/execute`, messages, interrupt/delete, computers) plus programmatic `GET /api/billing/limits` and a BYO-inference Free tier.
5. **[Warp Oz (Warp Factories)](https://www.warp.dev/oz)** (Warp · Fit 5/5 · `driver`) — Most observability-rich OpenAPI in the field (`POST /agent/run`, follow-ups, cancel/interrupt, `GET /agent/runs/{runId}/harness-usage`, `GET /factory/{uid}/costs/per-pr`), multi-harness (Warp/Claude Code/Codex), and self-hosted workers.
6. **[GitHub Copilot Cloud Agent](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/cloud-agent/use-cloud-agent-via-the-api)** (GitHub / Microsoft · Fit 5/5 · `driver (and harness row via Copilot CLI)`) — Official REST Agent Tasks API (`POST /agents/repos/{owner}/{repo}/tasks`) plus 6-language Copilot SDK cloud sessions, native GitHub workflow, and the lowest paid entry tier ($10/mo Pro).
7. **[OpenHands Cloud](https://www.openhands.dev)** (All Hands AI (OpenHands) · Fit 5/5 · `driver (and harness row for local OpenHands CLI)`) — MIT open-source core with V1 REST API (`POST /api/v1/app-conversations`, `send-message`, `DELETE`), multi-forge support (GitHub/GitLab/Bitbucket), ACP multi-agent support, and self-hosting.
8. **[Claude Managed Agents](https://platform.claude.com/docs/en/managed-agents/overview)** (Anthropic · Fit 5/5 · `driver (and model provider)`) — Anthropic's first-party stateful cloud harness API (`/v1/agents`, `/v1/environments`, `/v1/sessions`, SSE, `user.interrupt`, `/archive`, `max_list_cost` caps) with full self-hosted API parity.
9. **[OpenAI Agents API](https://developers.openai.com/api/docs/guides/agents-api/sessions)** (OpenAI · Fit 5/5 · `driver (and model provider)`) — OpenAI's first-party hosted runtime (`client.beta.agents.sessions.create` with `openai_hosted` sandbox, steering, streaming, webhooks) — the clean programmatic companion to Codex Cloud.
10. **[Replicas](https://replicas.dev)** (Replicas · Fit 5/5 · `driver`) — Complete REST API (`POST /v1/replica`, messages, `chats/{chatId}/interrupt`, sleep/wake/delete) + CLI, 7+ harnesses in full Chrome+Docker Linux VMs, and `GET /v1/organization/billing/balance`.
11. **[Tembo](https://www.tembo.io)** (Tembo · Fit 5/5 · `driver`) — Full OpenAPI (`POST /v1/sessions`, `POST /v1/sessions/{id}/stop`, `DELETE`) with official TypeScript and Rust SDKs, running 6+ harnesses across GitHub, GitLab, and Bitbucket.
12. **[Omnara Cloud](https://www.omnara.com)** (Omnara · Fit 5/5 · `driver`) — Apache-2.0 open-source managed agent control plane with $0 platform fee, durable Postgres recovery, REST API + TS SDK + CLI, and free BYO-keys/BYO-machines or pay-as-you-go cloud compute.
13. **[GitLab Duo Agent Platform](https://docs.gitlab.com/user/duo_agent_platform/)** (GitLab · Fit 4/5 · `driver (for GitLab repositories) and CI`) — Official Flows REST API (`POST /ai/duo_workflows/workflows`) and `duo` CLI — essential first-party cloud driver for GitLab-centric enterprise teams.
14. **[CodeRabbit Coding Agent](https://docs.coderabbit.ai/code)** (CodeRabbit · Fit 4/5 · `driver (and CI / PR review integration)`) — Complete idempotent REST API (`POST /v1/code/tasks`, turn polling, `POST /v1/code/tasks/{id}/cancel`), `coderabbit code` CLI (`--agent` JSON), and MCP server uniting code review with autonomous fixes.
15. **[Netlify Agent Runners](https://www.netlify.com/platform/agent-runners/)** (Netlify · Fit 4/5 · `driver (and CI/preview provider for web projects)`) — Newly launched public API (`POST /sites/{site_id}/agent_runners`) and `netlify agents:create`/`show` CLI included on the Free plan with live deploy previews for web tickets.

> **Notable runners-up (fit 4/5):** **Claude Code in the Cloud** (`claude --cloud`), **OpenAI Codex Cloud** (`codex cloud`), **Railway Cloud Agents** (GraphQL `cloudAgentTaskDispatch`), **Amp Orbs** (`amp -ox`), **Capy** (`api.capy.ai`), **Sinatra** (`api.sinatra.dev`), **Rush** (`api.phoenix.so`), **Superconductor** (`api/v1`), **Conductor Cloud** (`api.conductor.build/v0`, resumed Nov 13, 2026), **Ellipsis**, **Kilo Code Cloud Agents** (`kilo cloud`), **Coder Agents** (`/api/v2/chats`), **NeonCodex Cloud Agents**, **LatentStack Agents API**, and **MIOSA Cloud Agents**.
