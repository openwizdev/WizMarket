# CI Systems Census (2026-11-27)

Complete census of **85** Continuous Integration systems, runner clouds, forge-native CI engines, build-system/monorepo executors, and notable recently discontinued platforms as of November 2026.

- **Active:** 77 | **Maintenance:** 1 | **Discontinued (2025–2026):** 7
- **Structured data:** [`census/ci.json`](ci.json)
- **Note on drop-in GitHub Actions runner clouds** (Jog, Blacksmith, WarpBuild, RunsOn, Ubicloud, Tenki, Sprinters, Actuated, ARC): because these execute inside GitHub Actions via `runs-on` labels, they work automatically through OpenWiz's existing GitHub Actions checks provider, with optional CLI/API telemetry add-ons.

## Notable 2025–2026 Shutdowns & Pivots

Documented here so WizMarket does not build adapters for dead services:

- **Cirrus CI / Cirrus Runners**: Permanently shut down **2026-06-01** after the Cirrus Labs team joined OpenAI's Agent Infrastructure group (users migrated to GitHub Actions, WarpBuild, or OakHost + Tart/Cilicon).
- **BuildJet**: Permanently shut down its managed GitHub Actions runner service on **2026-03-31**.
- **JFrog Pipelines**: Reached End of Life on **2026-05-01** (both SaaS and self-managed).
- **Earthly Cloud & CLI**: Earthly Cloud and Satellites shut down **2025-07-16** and upstream corporate maintenance of `earthly/earthly` ended as Earthly pivoted to Earthly Lunar (community fork: EarthBuild).
- **webapp.io (formerly LayerCI)**: Acquired by Harness and shut down as a standalone platform on **2025-06-01**.
- **JetBrains Space Automation**: Discontinued **2025-05-31**; JetBrains directs CI users to TeamCity.
- **Garnix**: Announced closure and wound down its hosted Nix flake CI service.
- **CodeShip**: Resurfaced independently in mid-2026 under Codeship Labs after years under CloudBees (2026 API/pricing details unverified).
