## Notable 2024–2026 Shutdowns, Acquisitions & Maintenance Transitions

Documented here so WizMarket does not build adapters for dead or winding-down services:

- **GitHub Models (`models.github.ai`)**: Officially retired on **2026-07-30**; GitHub directs catalog users to **Azure AI Foundry** and coding users to **GitHub Copilot**.
- **Meta Llama API (`api.llama.com`)**: Public preview officially retired on **2026-07-06**; Meta directs Llama users to third-party inference clouds (Together, Fireworks, Groq, Bedrock) or local engines, while newer Meta proprietary models move to `api.meta.ai`.
- **TensorZero**: Wound down operations and archived `tensorzero/tensorzero` to read-only in **June 2026**; use **LiteLLM**, **Bifrost**, or **Portkey** instead.
- **Inception Labs (Mercury)**: Announced wind-down and shutdown of the Mercury diffusion LLM API scheduled for **2026-12-28**.
- **Lambda Inference API**: Serverless per-token inference API wound down; Lambda now focuses on direct on-demand/reserved NVIDIA GPU instances.
- **OctoAI**: Acquired by NVIDIA; standalone inference platform shut down and absorbed into **NVIDIA NIM** / DGX Cloud.
- **Lepton AI**: Acquired by NVIDIA and rebranded into **NVIDIA DGX Cloud Lepton**.
- **Anyscale Endpoints**: Discontinued serverless endpoints (migrated users to **Fireworks AI**; Ray Serve remains open source).
- **Hugging Face TGI (`text-generation-inference`)**: Shifted to formal **Maintenance Mode**; Hugging Face directs new deployments to **vLLM** or **SGLang**.
- **Perplexity Legacy Sonar Chat Completions**: Retired in favor of Perplexity's split **Orchestrator**, **Agent**, and **Search** APIs.
