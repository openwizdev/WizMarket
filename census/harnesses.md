# Coding-Agent CLI & Harness Census (2026-11-27)

Primary-source census of **104 coding-agent CLIs and programmatic harnesses** verifiable as of late November 2026 (94 active, 10 archived/sunsetting/maintenance/superseded/discontinued; 65 OSI open-source; 82 `harness row` fits, 21 `driver` fits, 1 `CI` fit).

All entries were checked against primary sources (official CLI/API documentation, pricing pages, changelogs, and GitHub repositories/LICENSE files). Fields that could not be verified from primary sources are marked `unverified`. Machine-readable data lives in [`harnesses.json`](harnesses.json).

## Notable Late-2026 Status Changes Caught by Primary Sources

- **Roo Code (`RooCodeInc/Roo-Code`)**: Shut down and archived on **2026-05-15** ([sunset notice](https://github.com/RooCodeInc/Roo-Code-Docs/blob/main/docs/sunset.md)).
- **Google Jules**: Stopped taking new sessions (read-only) on **2026-11-11** and shuts down **2026-12-31**; workflows are consolidating into Antigravity ([changelog](https://jules.google/docs/changelog/2026-10-29/)).
- **Windsurf -> Devin Desktop / Devin CLI**: Windsurf became Devin Desktop on **2026-06-02**; legacy Cascade was removed on **2026-09-08**, and Devin Local shares its harness with `devin` CLI ([FAQ](https://docs.devin.ai/desktop/devin-desktop-faq)).
- **Kimi CLI -> Kimi Code CLI**: Python `MoonshotAI/kimi-cli` is archived; replaced by MIT TypeScript `MoonshotAI/kimi-code`.
- **Amazon Q Developer CLI -> Kiro CLI**: `aws/amazon-q-developer-cli` is security-fix-only; replaced by closed-source `kiro-cli`.
- **OpenHands CLI**: Official docs warn `openhands` CLI is no longer actively maintained; use OpenHands Cloud API / Agent Canvas.
- **Sourcegraph Cody CLI**: End-of-life **2027-01-31**; replaced by Amp.
- **Tabnine CLI**: Maintenance mode through **2026-12-31**; replaced by Tabnine Plugin for OpenCode.
- **Atlassian Rovo Dev**: Standalone product reaching EOL as capabilities fold into Jira subscriptions.
- **iFlow CLI**: Discontinued **2026-04-17**.
- **DeepSeek-Reasonix**: Archived / unmaintained as of **2026-11-12**.
- **Codebuff -> Freebuff**: Rebranded to ad-supported free suite (`freebuff.com`).
